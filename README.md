# Tareas Ocasionales - App Nativa Android (Jetpack Compose)

Aplicación nativa en español para Samsung Galaxy S23 (Android 17) para registrar tareas según las ocasiones en que se pueden hacer ("Lo hice" / "No lo hice").

## Características Principales
- **Gestión de Tareas**: Crear, renombrar, ordenar, archivar y borrar.
- **Registro Detallado**: Botones separados «Lo hice» y «No lo hice». Guarda hora exacta, permite múltiples registros diarios, deshacer inmediato y corrección de historiales.
- **Recuentos e Historial**: Estadísticas para hoy, esta semana (Lunes a Domingo, hora local) y todo el tiempo. Filtros avanzados por tarea, día y semana.
- **Acceso Rápido por Notificación**: Notificación discreta (sin sonido ni vibración) con acceso directo al panel de registro.
- **Privacidad Total**: 100% local (Room Database), sin internet, sin anuncios ni analíticas.

## Instrucciones de Instalación y Compilación (APK)
1. Descarga y extrae este proyecto en tu ordenador.
2. Abre **Android Studio** (versión Ladybug o superior recomendada para Android 17 / SDK 35+).
3. Selecciona **File > Open** y selecciona la carpeta raíz del proyecto extraído.
4. Conecta tu **Samsung Galaxy S23** con la depuración USB activada (Opciones de desarrollador).
5. Haz clic en el botón **Run** (▶️) en Android Studio para compilar e instalar automáticamente el APK en tu dispositivo, o ve a **Build > Build Bundle(s) / APK(s) > Build APK(s)** para generar el archivo instalable `app-debug.apk`.
